# Архитектура Yamaha AIR

## Цель

Мониторинг эфирного звука с USB-микшера Yamaha TF. Пользователь сводит эфир
(речь, музыкальные концерты) и хочет видеть в реальном времени уровни, громкость
(LUFS), динамику, спектр и баланс инструментов — чтобы понимать, почему звук
неприятный и что исправить (громкость или EQ).

## Поток данных

```
USB-микшер (TF, 16 каналов USB)
   │  AVAudioEngine (inputNode + installTap, N каналов)
   ▼
AudioCaptureImpl (rt-поток: копирует каналы → Frame)
   │  DispatchQueue.global().async (не блокируем аудио-поток)
   ▼
AudioDataPublisher.ingest(Frame)
   │  для каждого канала: ChannelAnalyzerSet
   │    ├─ VUMeter        (RMS, attack/release 300мс)
   │    ├─ DynamicsAnalyzer (peak, truepeak, crest, clip)
   │    ├─ LoudnessMeter (R128: momentary/short/integrated/LR)
   │    └─ FFT → SpectrumAnalyzer (лог-сетка, 24 pt/octave)
   │  гейт по updateRate (15 Гц)
   ▼
AnalysisSnapshot (Sendable)
   │  Task { @MainActor in ... }
   ▼
SwiftUI (Monitor / Spectrum / Balance / Settings)
```

## Ключевые решения

### 1. Захват через AVAudioEngine, а не AudioUnit/HAL IOProc
- `AudioUnit` (HALOutput) и `AudioDeviceIOProc` при запуске из CLI не давали
  данных (возвращали noErr, но колбэки не вызывались).
- `AVAudioEngine` + `installTap` на `inputNode` работает стабильно, включая
  CLI-контекст, и поддерживает N-канальный мультиплекс (для Loopback отдаёт
  то, что реально поддерживает устройство; для TF — 16 каналов).

### 2. Асинхронная доставка из аудио-потока
- НЕЛЬЗЯ делать тяжёлую работу или синхронно писать в stderr на аудио-потоке:
  поток замирает (было воспроизведено).
- `AudioCaptureImpl` копирует каналы и отдаёт Frame через `DispatchQueue.global`.
- Вся DSP-обработка идёт на фоне; UI получает снимки редким гейтом.

### 3. DSP-изоляция
- `uaDSP` — чистые алгоритмы без AppKit/AVFoundation (можно юнит-тестить).
- `yaCore` — аудио-движок + сборка снимков.
- `air-app` — только SwiftUI.

## Точность и калибровка

### LUFS (EBU R128 / ITU BS.1770-4)
- K-weighting: high-shelf (+4 дБ, RS=1.5147, f≈1.68 кГц) → high-pass (38.135 Гц).
- Блоки 400 мс; momentary; short-term = 3 с (скользящее среднее по блокам).
- Integrated с gating: absolute -70 LU, relative -10 LU от максимального уровня.
- LR: 10-й и 95-й процентили распределения блоков.
- НЕ гарантирует эталонной точности до сотых: реализация приближена к R128,
  но для практического мониторинга (±1 дБ) достаточно. Для точной аттестации
  нужен re-validated против тестовых файлов (EBU Tech 3341).

### Уровни
- Показываются в дБFS относительно цифровой полной шкалы USB-интерфейса.
- Реальный уровень на выходе пульта зависит от настроек USB gain на TF
  (SETUP → USB). Можно ввести калибровочный офсет (см. «План»).

## Развитие (v0.2+)

1. **Выбор устройства с реальным канальным count**
   - Сейчас AVAudioEngine принудительно создаёт формат с N каналами; для
     TF-карт это работает. Для USB-класса 1/2 (как у старых MG) — только 2.
2. **Калибровка уровня**
   - Офсет дБ (вручную или по референсному сигналу -20 dBFS на пульте).
3. **Режимы анализа** (конфигурация, как в подобных инструментах)
   - FFT size (2048…65536), окно (Hann/Hamming/Blackman), частота обновления,
     averaging/peak-hold, сглаживание.
   - Выбор метрик на вкладке (что показывать).
4. **Баланс микса — лучше**
   - Калибровка референсной кривой под жанр/зал.
   - Рекомендации: «убавить 3 дБ на 200 Гц» (по отклонению полосы).
   - Опционально: source separation (Demucs) оффлайн — отдельные стемы.
5. **Стерео-анализ**
   - Раздельный L/R, связка (mid/side), фаза, correlation.
6. **Запись/файлы**
   - Логирование метрик, экспорт отчёта по эфиру.
7. **Производительность**
   - Переиспользование буферов, автоснижение FFT при нагрузке.

## Известные ограничения

- `air-aio` (CLI) выводит в stderr; в GUI тот же движок работает через AppModel.
- При запуске из CLI без прав микрофона macOS может тихо не давать данных —
  для GUI добавлен `NSMicrophoneUsageDescription`.
- Loopback-устройства заявляют N каналов, но реально отдают меньше; приложение
  показывает то, что приходит, и фильтрует по выбранным индексам.
