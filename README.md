# AirMonitor

Мониторинг звука в эфире. Приложение для macOS (Apple Silicon и Intel) анализирует
сигнал с многоканального USB-аудиоинтерфейса (например, цифрового микшера или любого многоканального USB-
интерфейса) и показывает уровни, LUFS, динамику, спектр (АЧХ) и баланс микса.

## Возможности

- Выбор входного аудиоустройства (USB-микшер) и отдельных каналов для анализа
- Одновременный анализ нескольких каналов (main, monitor, отдельные входы)
- VU/пики/RMS/TruePeak, crest factor, клиппинг
- LUFS: momentary, short-term, integrated, динамический диапазон (LR)
- Спектр (АЧХ) на лог-шкале — для поиска резонансов и проблемных частот
- «Баланс микса» — энергия по частотным полосам инструментов (суб, бас,
  бочка, середина, вокал, сибилянты, верх) с отклонением от референса
  и подсказкой по коррекции EQ

## Стек

- Swift 6, SwiftUI, macOS 14+
- Захват: `AVAudioEngine` (inputNode + installTap), поддержка N каналов
- DSP: `Accelerate/vDSP` (FFT), онлайн-алгоритмы VU/LUFS/R128

## Структура

```
Sources/
  yaCore/      — аудио-движок (AudioEngine, AudioCapture), публикация данных
  uaDSP/       — DSP: FFT, VUMeter, LoudnessMeter (R128), DynamicsAnalyzer,
                 InstrumentBalance
  air-monitor/ — SwiftUI-приложение (монитор, спектр, баланс, настройки)
  air-aio/     — CLI-утилита для отладки захвата
  dspcheck/    — самопроверка DSP-модулей
```

## Сборка и запуск

```bash
# Сборка и проверка DSP
swift build
swift run dspcheck

# Список аудиоустройств
swift run air-aio --list

# Захват с конкретного устройства (тест)
swift run air-aio "Loopback"

# Собрать .app и запустить
./Tools/build_app.sh
open dist/AirMonitor.app

# Собрать универсальный установочный образ для Apple Silicon и Intel
./Tools/make_dmg.sh
```

## Подключение аудиоустройства

TF-серия подключается по USB и видна как многоканальная звуковая карта
(обычно 16 входных каналов). Что идёт на USB, настраивается на пульте:
`SETUP → USB`. Рекомендуемая схема для мониторинга:

- 2 канала USB ← main L/R (для анализа микса)
- 2 канала USB ← monitor-выход (для сравнения)
- отдельные каналы — при необходимости для анализа отдельных входов

## Какая математика внутри

- **VU**: RMS-интегратор, attack/release 300 мс
- **LUFS (R128)**: K-weighting (high-shelf +4 дБ @ ~1.7 кГц, high-pass 38 Гц),
  блоки 400 мс, gating -70 LU / relative -10 LU, интегрированный + LR
- **FFT**: vDSP, Hamming/Hann окно, лог-частотная сетка 24 точки/октава
- **Баланс**: средняя энергия в полосах инструментов против референсной кривой
  (речь/музыка)
