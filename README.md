# AirMonitor

AirMonitor — приложение для macOS 14 и новее, которое анализирует входной звук
в реальном времени. Поддерживаются Apple Silicon и Intel, встроенные микрофоны,
аудиоинтерфейсы, многоканальные микшеры и виртуальные входы, например Loopback.
Для анализа системного воспроизведения нужен виртуальный аудиовход с настроенной маршрутизацией.

## Возможности

- Несколько независимых шин с выбором устройства и каналов, стереопары L/R и моно.
- Текущий RMS, накопленные Sample Peak и оценка True Peak, интегральная громкость I.
- Momentary M на окне 400 мс, Short-term S с настраиваемым окном, Loudness Range LRA.
- График громкости по времени, отдельные L/R и суммарная стереогромкость.
- Спектральный RTA-анализ с полосами по октавам, тонкой кривой, сглаживанием и peak hold.
- Корреляция L/R и crest factor на дашборде.
- Настраиваемый дашборд с перестановкой, скрытием, изменением размеров, переносом
  инструментов между строками, автопереносом и растягиванием графиков.
- Сохранение сцен и настроек, русский и английский интерфейс, светлая, тёмная и системная темы.
- Команды мониторинга, сцен, навигации, языка, темы, вида дашборда и настроек
  инструментов в верхнем меню macOS.
- Проверка обновлений во вкладке «О приложении», автоматическая проверка раз в сутки,
  загрузка и установка подписанных обновлений через Sparkle.

«Баланс микса» находится в разработке. Его текущие графики и подсказки экспериментальны.

## Обозначения и измерения

- M и S выражены в LUFS и учитывают K-взвешивание. Стандартное окно S — 3 с.
  При выборе другого окна S становится пользовательским индикатором.
- I выражена в LUFS и измеряется с начала захвата с абсолютным порогом −70 LUFS
  и относительным порогом −10 LU от энергетического среднего после первого гейта.
- LRA выражена в LU. Используются 3-секундные окна независимо от настройки S,
  выборки 10 Гц, абсолютный гейт −70 LUFS, относительный −20 LU и перцентили 10/95.
- Дополнительное сглаживание чисел и графика M/S влияет на отображение.
  I и LRA от этих настроек не меняются. LUFS-офсет задаёт поправку M/S/I.
- RMS выражен в dBFS и сглажен с атакой около 30 мс и спадом около 150 мс.
  Peak в dBFS и TruePk в dBTP накапливают максимумы с начала измерения.
- True Peak оценивается 4-кратной передискретизацией. Реализация не проходила
  сертификацию на соответствие полному набору тестов ITU/EBU.
- Спектр показывает частотный состав входного сигнала. Для измерения передаточной
  АЧХ помещения или устройства нужны также тестовый сигнал и опорное измерение.
- −23 LUFS на графике — ориентир EBU R 128. При цифровой тишине M/S опускаются
  к пределу отображения −120 LUFS. I сохраняет интегральное значение после гейтинга.

## Установка и обновления

Откройте DMG и перетащите AirMonitor.app в «Программы». Для захвата звука разрешите
доступ к микрофону, когда macOS его запросит. Во вкладке «О приложении» находятся
версия, ссылка на репозиторий, выбор языка и темы, проверка обновлений и
переключатели автоматической проверки и загрузки. Установка обновления требует
завершения приложения. Те же основные действия доступны в верхнем меню macOS.

Версия 1.0 была выпущена без встроенного обновления. Для перехода с 1.0 на 1.2
установите [DMG релиза 1.2](https://github.com/Davydov-Andrej/AirMonitor/releases/tag/v1.2)
вручную. Начиная с версии 1.2 приложение может автоматически устанавливать
последующие релизы, если в них опубликованы оба файла — DMG и `appcast.xml`.

## Сборка

Требуются Swift 6 и macOS Command Line Tools. Swift Package Manager получает
Sparkle 2.10.1. Версия приложения задаётся файлом `VERSION`.

```bash
swift build
swift run dspcheck
swift run air-aio --list
./Tools/build_app.sh
open dist/AirMonitor.app
./Tools/make_dmg.sh
```

`build_app.sh` создаёт локальное приложение для архитектуры компьютера.
`make_dmg.sh` создаёт универсальный DMG для arm64/x86_64 и `dist/appcast.xml`.
Пакет обновления подписывается Ed25519-ключом из Связки ключей с именем аккаунта
`com.airmonitor.app`. В исходниках и приложении хранится только публичный ключ.
Для сборки на другом компьютере нужен перенос ключа подписи средствами Sparkle.

Публикация выполняется отдельно после проверки сборки. В GitHub Release с тегом
`v<версия>` загружаются DMG и `appcast.xml`. Автообновление использует публичный
репозиторий `Davydov-Andrej/AirMonitor`, HTTPS и проверку подписи пакета.

## Код

- `Sources/air-monitor` — интерфейс SwiftUI/AppKit и обновление приложения.
- `Sources/yaCore` — захват выбранных устройств через CoreAudio AUHAL, доставка данных.
- `Sources/uaDSP` — уровни, громкость, FFT и RTA на Accelerate/vDSP.
- `Sources/air-aio` — диагностика входных устройств и захвата из терминала.
- `Sources/dspcheck` — проверки DSP на синтетических сигналах.
- `Tools` — сборка приложения, иконки, DMG и подписанного канала обновлений.

Описание архитектуры и направлений развития находится в `Docs/ARCHITECTURE.md`.
